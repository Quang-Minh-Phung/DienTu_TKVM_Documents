*   **Mục tiêu**: Hiểu tại sao cần kiểm thử phần cứng, các mô hình lỗi (Stuck-at, Transition, Path Delay) và cách tạo vector kiểm thử (ATPG).
*   **Tài liệu học tập cục bộ**:
    *   📖 Giáo trình nền tảng về mô phỏng: _Digital logic testing and simulation.pdf *(Rất tốt để hiểu về cơ chế mô phỏng lỗi và thuật toán sinh vector kiểm thử)*.

### 🏛️ 2. Sách Giáo Trình Kinh Điển Về Kiến Trúc DFT
*   **Mục tiêu**: Nắm vững các cấu trúc thiết kế DFT cốt lõi trong chip thương mại như Scan Design, Built-In Self-Test (BIST) cho RAM/Logic, và Boundary Scan (JTAG IEEE 1149.1).
*   **Tài liệu học tập cục bộ**:
    *   📖 Sách gối đầu giường về DFT: _VLSI-Test-Principles-and-Architectures-Design-for-Testability.pdf *(Tài liệu cực kỳ đầy đủ, chi tiết từ lý thuyết đến kiến trúc phần cứng thực tế)*.
    *   📖 Tiếp cận qua ngôn ngữ mô tả phần cứng: _Digital-System-Test-and-Testable-Design-Using-HDL-models-and-Architectures.pdf *(Hướng dẫn cách tích hợp các khối test bằng Verilog/VHDL)*.
